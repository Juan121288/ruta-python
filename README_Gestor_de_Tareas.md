#Gestor de Tareas 📝

Aplicación de consola escrita en Python para gestionar una lista de tareas pendientes. 
Proyecto de práctica dentro de mi ruta de aprendizaje de Python ("Ruta Python"), 
enfocado en reforzar lógica de programación: bucles, condicionales, listas y manejo de errores.

Funcionalidades

  Agregar una nueva tarea a la lista
  Ver todas las tareas numeradas
  Eliminar una tarea por su número
  Salir del programa de forma controlada
  
Cómo ejecutarlo

  python3 main.py
  
Conceptos de Python aplicados

  Listas y el método .append()
  Bucles while y for
  Estructuras condicionales if / elif / else
  La función enumerate() para recorrer listas con índice
  F-strings para formatear texto
  Manejo de errores con try / except
  
Próximos pasos

Este es el primer proyecto de una serie orientada a explorar distintas áreas de Python: 
automatización, ciberseguridad, backend y datos.
